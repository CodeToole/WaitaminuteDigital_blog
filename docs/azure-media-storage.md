# Azure Blob Storage for Django media

This project stores uploaded media for portfolio and blog content. The default local App Service filesystem is not durable across deployments, restarts, or slot swaps. For production Azure hosting, use Azure Blob Storage for uploaded images.

## Required Azure configuration

Create a storage account and a blob container:

- Storage account: `waitaminutedigitalmedia` (example)
- Container: `media`
- Access tier: Hot
- Public access: disabled for private media, or enable the blob endpoint as needed
- Shared key auth enabled

Create the following environment variables in Azure App Service configuration:

```env
USE_AZURE_BLOB=True
AZURE_ACCOUNT_NAME=waitaminutedigitalmedia
AZURE_ACCOUNT_KEY=your-storage-account-key
AZURE_MEDIA_CONTAINER=media
AZURE_CUSTOM_DOMAIN=
```

If you use a custom CDN or custom domain, set `AZURE_CUSTOM_DOMAIN` to the public hostname for the blob endpoint, for example:

```env
AZURE_CUSTOM_DOMAIN=media.waitaminutedigital.com
```

## Why this fixes the issue

The database stores the relative path (for example `projects/cover.png`), but the actual file must exist in the configured storage backend. When files are saved to the App Service local filesystem, they are lost after deployment or restart. Using Azure Blob Storage keeps those files in durable object storage.

## Migration steps

1. Back up the current local media directory:

```bash
mkdir -p backup/media
cp -R media backup/media/
```

2. Upload existing project and blog files to Azure Blob Storage using the same relative paths:

```bash
az storage blob upload-batch \
  --destination media \
  --source media \
  --account-name <storage-account-name> \
  --account-key <storage-account-key>
```

3. Set the Azure App Service app settings above.

4. Redeploy the app.

5. Verify the media URLs generated by Django match the blob endpoint, for example:

```text
https://<storage-account-name>.blob.core.windows.net/media/projects/cover.jpg
```

6. Re-test the homepage featured work, portfolio cards, and project detail pages.

## Persistence guarantees

Azure Blob Storage persists across:

- deployment
- app restart
- scale out
- slot swap

This is the recommended production setup for uploaded media in Azure App Service.
